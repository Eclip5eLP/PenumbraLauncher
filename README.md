# Penumbra Games Launcher

Desktop launcher for everything published on [eclip5e.com](https://eclip5e.com): games, software and web links.
Install, update (delta, resumable, verified), launch, sign in with a Penumbra Account, sync settings and saves.
The launcher updates itself.

- Platform: Windows 10/11 (x64)
- Stack: Tauri 2 (Rust) + Svelte 5 + TypeScript
- Server: `https://eclip5e.com/penumbra/` (static content + small PHP API), accounts via `https://accounts.eclip5e.com`

Status: **planning**. See [docs/README.md](docs/README.md) for the full design and [docs/10-roadmap.md](docs/10-roadmap.md)
for progress.
