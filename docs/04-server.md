# 04 — Server

Server internals (host, containers, limits, access) are in the private notes on the dev branch.
Relevant public facts: PHP 8.5 + Apache behind Cloudflare; `www/penumbra/` is served as `https://eclip5e.com/penumbra/`;
accounts at `https://accounts.eclip5e.com` (userbase, bearer tokens validated with its `token_lookup()`).

## Folder layout `www/penumbra/`
```
penumbra/
  .htaccess                 cache headers, deny data/, PHP routing
  index.php                 landing page: "Download Penumbra Launcher"
  api/v1/
    catalog.php             GET → signed catalog (public, or personalised with Bearer token)
    manifest.php            GET ?item=&version= → manifest (+sig); checks access for gated items
    news.php                GET ?item= → news/banners (static JSON fallback)
    saves.php               cloud saves > userbase limits (later, M7)
    stats.php               POST playtime/launch counts (later, optional, anonymous unless signed in)
    _lib.php                bootstrap: includes userbase lib, json helpers, CORS-free (launcher is not a browser)
  catalog/                  published catalog.json + catalog.sig (generated by penumbra-pack)
  content/<item>/manifests/<version>.json.zst (+ .sig)     public items
  data/                     DENY ALL: gated manifests, catalog source, access lists
  chunks/<xx>/<hash>.bin    global chunk store
  media/<item>/             icon.webp, logo.webp, bg.webp, bg.webm, banners/*.webp
  launcher/
    latest.json             Tauri updater manifest (stable)
    latest-beta.json
    PenumbraLauncher_<ver>_x64-setup.exe (+ .sig)
```

## HTTP API (v1)
All responses JSON, UTF-8. Errors: `{"error": "<code>", "message": "..."}` with proper status.

### `GET /penumbra/api/v1/catalog.php`
Optional `Authorization: Bearer <access token>` (Penumbra Account). Supports `If-None-Match`.
```jsonc
{
  "format": 1, "generated": "...", "mirrors": ["https://eclip5e.com/penumbra/"],
  "announcements": [ { "id": "...", "title": "...", "url": "...", "until": "..." } ],
  "groups": [ { "id": "games", "name": "Games" }, { "id": "software", "name": "Software" }, { "id": "links", "name": "Web" } ],
  "items": [
    { "id": "gracidea", "type": "game", "group": "games", "name": "Pokemon Gracidea",
      "tagline": "...", "description": "...",
      "media": { "icon": "media/gracidea/icon.webp", "logo": "...", "bg": "...", "bgVideo": null, "accent": "#c25" },
      "access": "public",          // public | account | restricted   (restricted items only appear if entitled)
      "locked": false,             // true if access=account and no/invalid token
      "channels": { "stable": { "version": "1.2.2", "size": 734003200, "download": 512000000 },
                    "beta":   { "version": "1.3.0-b2", "access": "role:tester" } },
      "launch": { "exe": "...", "args": [] },
      "cloudSaves": { "paths": ["%APPDATA%/Gracidea/Saves/**"] },
      "passToken": false,
      "links": { "website": "https://eclip5e.com/development/Gracidea/", "discord": "..." }
    },
    { "id": "pgdb", "type": "link", "group": "links", "name": "PG Database", "url": "https://pg.eclip5e.com/" }
  ]
}
```
Signed: the response carries `X-Penumbra-Sig: <ed25519 base64>` over the body. Personalised responses are signed
on the fly? → No (private key must not be on the server). Instead: the server only *filters* a pre-signed list.
Decision: the catalog is signed **per item** (`"sig"` field per item entry, signed by penumbra-pack), and the
launcher verifies each item it uses. Manifests are signed as well, and chunk hashes come from manifests, so even
a compromised server can't make the launcher install unsigned code. (ADR-007)

### `GET /penumbra/api/v1/manifest.php?item=<id>&version=<v>`
Returns `{ "manifest": <json>, "sig": "<base64>" }` (or 302 to the static file for public items, so
Cloudflare caches it). 401 `login_required`, 403 `forbidden` for gated items.

### Access check
`_lib.php`: read bearer token → `Userbase\token_lookup()` → user (id, username, role). Access rules from
`data/access.json`: `public`, `account`, `role:<role>`, `users:[ids]`. Token must belong to app `000007`.

## Caching & bandwidth
- Cloudflare in front: chunks + media + public manifests are immutable → edge cached, offloading home upload.
- `catalog.php` → `Cache-Control: no-cache` + ETag (cheap 304s).
- Apache serves static files directly (PHP not involved for downloads).
- `mirrors` list in catalog allows adding another origin later (e.g. a VPS or R2 bucket) with zero client changes.
- Risk: Cloudflare's terms for serving large binaries on the free plan and the home upload speed. Mitigations:
  chunks ≤ 16 MB, mirrors list. Track in open-questions.md.

## Deploy
Code (`server/penumbra/`) is deployed with a private deploy script; content (chunks/manifests/media/catalog) only
by `penumbra-pack`, never by the code deploy (so a code deploy can't delete content).
